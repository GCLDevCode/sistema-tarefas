# Sistema Web de Gestão de Tarefas

Projeto inicial para organização de tarefas.

## Pré-requisito

* Python 3 instalado.

## Execução

Crie o ambiente virtual:

```bash
python -m venv .venv
```

Ative o ambiente virtual:

### Windows

```bash
.venv\Scripts\activate
```

### Linux/macOS

```bash
source .venv/bin/activate
```

Execute o projeto:

```bash
python main.py
```
